Selected system
Hospital appointment system
Problem statement
Booking a appointment hospitals is still a manual process where a patient who wants to see a doctor has to call the hospital during working hours or be physically present at the hospital to describe their problem to a receptionist who then decides which doctor is appropriate, and accept whatever time slot happens to be free. If the patient later needs to change or cancel, the whole cycle repeats and this may lead to to appointments history may be lost and the patients can’t see real availability of the doctors directly and increase lose of revenue lost on the appointment bookings
Target users
Patients
Doctors
Hospital administrators

Importance of this system
The system will enable the patient to view the doctor’s availability direct
The system will keep the appointment record ensuring the patient and doctors to ccess the appointment history easier 
The system will reduces the workload on other hospital staff
The system will automatically remind the patient of the appointment before time

Design explanation
We used a inter font through out the whole project in three weight (regular for body text, medium for labels, and semi-bold for headings.) and used an 8 point spacing system is used for margins, so that spacing is consistent on every screen. Content is grouped inside rounded white cards with soft shadows, which makes each block of information easy to scan.
Repeated elements were built as Figma components like the doctor card, the department chip, the appointment row, the status tag, the avatar, the input field and the primary button , so that a change to a component updates every screen.
Auto Layout was applied to lists, filter rows and cards so that content resizes correctly when text length changes.
Doctors are represented by initials in a coloured circle rather than photographs, which keeps the design consistent and avoids using images of real people.

We also used colour variable to be able to switch from dark to white easy

Accessibility Considerations
•	Colour contrast: dark text on white cards and white text on the deep teal primary colour, so text remains readable for users with low vision.
•	Readable font sizes: body text at 14–16 px and headings clearly larger, with a text-size setting in the profile screen that allows the user to increase text to "Large".
•	Clear navigation: the navigation bar is present on every main screen, the current position is always highlighted, and the web version adds a breadcrumb (Find a doctor › Cardiology › Dr. Diane Mukamana).
•	Consistency: the same components, colours and spacing are used on every screen, so a user only has to learn the interface once.

conclusion
This project produced Care Link, a responsive hospital appointment system prototype designed in Figma for both mobile and web. Starting from a clear problem – the manual, queue-based booking process used in most hospitals – we identified the target users, built personas, mapped the user flow, produced low-fidelity wireframes, and developed them into fourteen high-fidelity screens connected as a clickable prototype.
The design allows a patient to see real doctor availability, book a suitable slot themselves, receive automatic reminders, and reschedule or cancel without returning to the hospital, while giving the hospital a permanent and searchable record of every appointment.
